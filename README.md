# ヤマハ電子ドラム 現行モデル 比較・診断

ヤマハの現行電子ドラムセット全14モデルを1ページにまとめた、非公式の比較サイトです。

**公開ページ:** https://tommy10310124.github.io/yamaha-edrums/

## 中身

| タブ | 内容 |
|---|---|
| 条件から選ぶ | 予算・静音性・スペース・目的・打感・ペダルの6問に答えると、おすすめ1モデルと次点3モデルを提示 |
| 全モデル比較表 | 全14モデルの仕様を横並びで比較。シリーズ絞り込みと、列の絞り込み（パッド構成／付属品）付き |
| 音源・関連機器 | DTX-PRO / DTX-PROX などのモジュールと周辺機器 |
| 付属品・アクセサリー | 同梱品の一覧、別途必要なもの、買い足し用パッドとラックの価格 |
| 型番の読み方 | `DTX6K3-XUPS` のような型番の分解と、各記号の意味 |

## 対象モデル

- **DTX402シリーズ** — DTX402KS / DTX432KS / DTX432KUPGS / DTX452KS / DTX452KUPGS
- **DTX6シリーズ** — DTX6K-XFS / DTX6K2-XFS / DTX6K3-XUPS / DTX6K3-XUPD / DTX6K5-MUPS
- **DTX8シリーズ** — DTX8K-M / DTX8K-X
- **DTX10シリーズ** — DTX10K-M / DTX10K-X

## 技術的なこと

`index.html` 1枚だけの静的ページです。ビルド不要、外部リソースへの依存なし（CDN・Webフォント・画像の読み込みが一切ありません）。モデルデータはファイル末尾の `MODELS` 配列にまとまっているので、価格や仕様の更新はそこを書き換えるだけで表と診断の両方に反映されます。

ライト／ダークの両テーマに対応しています（閲覧環境の設定に追従）。

## 出典・注意

価格・仕様はヤマハ株式会社の公式サイト（jp.yamaha.com）の製品情報および仕様ページにもとづく、2026年8月時点の内容です。ヤマハとは無関係の非公式なまとめであり、購入前には必ず公式サイトと販売店で最新情報を確認してください。

型番の意味については、ヤマハが命名規則を公開していないため、公式に明示されている部分とラインナップから逆算した部分をページ内で区別して記載しています。
